# Contributing to ds (do-shit)

Thanks for your interest in contributing! 🎉  
`ds` is an open source project designed to help developers manage tasks and workflows from the CLI, backed by a Rails API. Contributions are welcome — whether it's bug fixes, new features, documentation, or ideas.

---

## 🧭 How to Contribute

1. **Fork the repo** and create a branch:
   ```bash
   git checkout -b feature/my-feature
   ```
